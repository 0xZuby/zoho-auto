# Employee Onboarding Prototype Implementation Plan

1. Create a workspace layout with `frontend` (Next.js) and `backend` (Express), plus focused README and environment templates.
2. Implement the backend domain model, validation, MongoDB repository, dashboard-safe projection, and idempotent simulated provisioning endpoints.
3. Add automated API tests using an in-memory MongoDB server.
4. Build the responsive employee form and confirmation experience in the frontend.
5. Build the dashboard and request-detail/review/provisioning views, ensuring only the submission timestamp is visible in its list.
6. Install dependencies, run backend tests, frontend linting/type checks, and correct issues.
